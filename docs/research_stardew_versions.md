# 星露谷物语版本更新研究与 1.6 / 1.7 对齐选择

> 目的：从版本演进中提炼“为什么改、改成什么逻辑、交互怎么做”，再把适合本项目的部分纳入阶段计划。
> 结论以官方 changelog 与中文 wiki 为主；1.7 仅有少量官方确认，传闻单独标注。

## 1. 从发布到 1.6 的版本脉络

| 版本 | 时间 | 核心改动（与农场模拟相关） | 设计目的 / 逻辑 |
|---|---|---|---|
| 1.0 | 2016-02 | 核心循环：耕种、养殖、矿洞、社区中心、婚姻、节日、四季 | 建立“白天劳作—夜晚结算—季节推进”的基础节奏 |
| 1.1 | 2016-10 | 谢恩/艾米丽成为可婚对象；配偶在农场有专属小天地；新增小屋、磨坊；不同农场地图差异化 | 强化“婚后生活”与农场个性化，让农场地图影响玩法 |
| 1.2 | 2017-04 | 六种新语言、手柄操作、稳定性修复 | 全球化与可访问性，扩大受众 |
| 1.3 | 2018-08 | 多人合作（最多 4 人）、联机同步与聊天 | 把单人农场变成社交空间 |
| 1.4 | 2019-11 | 电影院、配偶 14 心事件、裁缝/染色、四角农场、鱼塘、大量 QoL | 补后期内容与便利性，降低重复劳动 |
| 1.5 | 2020-12 | 姜岛（新区域/火山地牢/海岛农场）、海滩农场、锻造附魔、特别订单、完美度、困难矿洞、高级开档选项 | 大型后期扩展：新目标、新地图、新成长线 |
| 1.6 | 2024-03 | 精通系统、草甸农场、新节日、书籍商人、大箱子、新作物、NPC 冬装、地图实时位置、平衡与 QoL 大修 | 给中后期“再成长”的目标，提升生活感与交互密度 |
| 1.6.9/1.6.15 | 2024-11/12 | 主机/移动端对齐；存档修复、性能与联机修复 | 多平台一致性 |

**演进逻辑（一句话）**：1.1 让“婚后/农场”有差异 → 1.3 加社交 → 1.4/1.5 补后期与便利 → 1.6 用“精通 + 新农场 + 高密度生活细节”延长中后期目标。

## 2. 1.6 重点功能、逻辑与交互拆解

### 2.1 精通系统（Mastery）
- 逻辑：五项技能全部达到 10 级后，经验转为“精通经验”，在新增区域解锁精通等级与强力奖励（工具/戒指/配方等）。
- 交互：新区域入口 + 精通进度条 + 逐级解锁奖励；属于“满级后的第二条成长线”。
- 对本项目：可直接映射为 Phase 3 的“技能/经验”模块：技能满级后进入精通池，按阈值解锁被动/工具升级。

### 2.2 草甸农场（Meadowlands Farm）
- 逻辑：新农场类型，蓝草（动物喜爱）、开局自带鸡舍与 2 只鸡；减少前期养殖门槛。
- 交互：新档选农场类型 → 地图/初始建筑/动物不同。
- 对本项目：Phase 4 的“农场类型”扩展模板；先做数据驱动农场定义，再做第二种地图。

### 2.3 节日与活动
- 沙漠节（春季三天，需修复巴士）、钓鱼小游戏节（Trout Derby、SquidFest）、夏季环境事件。
- 逻辑：节日=限时地点+小游戏+专属货币/奖励；节日地图与对白每两年变化。
- 对本项目：先做“节日框架”（日期/地点/入场/小游戏/奖励），Phase 4 接一个最小节日即可验证框架。

### 2.4 物品与机器（对经济系统的影响）
- 大箱子（容量约两倍、可套在普通箱上升级）；脱水机（水果→果干）；蘑菇原木；鱼饵制造机；重型熔炉；熏鱼机（鱼价值翻倍）；文字牌；铁砧；迷你锻造；祝福雕像；帐篷套件；宝藏图腾；神秘种子/神秘糖浆；19 本能力书、技能书；苔藓；混合花种；声呐浮标；葡萄干；海/河/洞穴果冻；7 个饰品；烟花；星之果实茶；25 帽子、280 家具、41 地板、24 壁纸；金色动物饼干；人体模型；配偶画像；蝴蝶粉；蓝草种子。
- 逻辑：机器=输入→时间→输出，叠加“品质/价值倍率”；箱子=容量升级路径。
- 对本项目：优先“大箱子/箱子容量”和“加工机器”通用框架（输入槽/计时/产出），其余作为内容表扩展。

### 2.5 NPC、社交与宠物
- 大量新对白：定制礼物反应、动态对白、花舞接受对白、恢复缺失对白；NPC 冬季服装。
- 可多宠物（初始宠物满心后）；宠物送礼；猫狗戴帽子；乌龟宠物；两种新猫狗品种；宠物碗（三种）可建造；农场与宠物碗可移动。
- 逻辑：社交从“固定台词”升级为“状态驱动对白”（事件/关系/季节/天气）。
- 对本项目：Phase 3 做“对白条件表”（季节/好感/天气），Phase 4 做多宠物/宠物碗。

### 2.6 地图与视觉
- 世界地图显示玩家实时位置；姜岛地图；季节地图变体；瀑布；冬季节日装饰；南瓜灯；彩色果酱/腌菜/酒/汁；城镇树变实体；室内图形改进；光照整体升级（冬季提前变暗、夜间灯提前亮、室内两小时平滑过渡、雨天农舍氛围光）。
- 逻辑：视觉信息与“当前状态”绑定（位置/季节/天气/时间），不是纯装饰。
- 对本项目：Phase 3 做“时间/天气驱动的光照与季节贴图”；Phase 4 做小地图/实时位置。

### 2.7 平衡与惩罚（最值得抄的逻辑）
- 昏倒惩罚改为“按持有金币比例缩放”，上限从 5000g 提升到 15000g；不再丢失金色镰刀/无限武器/工具，最多丢 3 件物品。
- 草在冬季存活但不蔓延、冬季割草收益大减；蘑菇洞改为隔天产出；随机数去规律化（防“黏土农场”等预测）。
- 逻辑：惩罚随进度缩放，避免“早期过痛、后期无感”；随机性不可被简单预测。
- 对本项目：Phase 3 把昏倒罚金改为比例+上限，并加“工具不掉落”。

### 2.8 交互与 QoL
- 蓄力浇水壶/锄头时可“横移”调整命中区，不改变朝向；通知停留时间 +50%；地图再按一次关闭；物品菜单退出时必定取回手持物；钓鱼首次收集闪光提示；箱子可被重工具推走；家具可放建筑下方地板；机器/箱子 UI 细节修复。
- 逻辑：降低误操作成本，让“手”和“意图”一致。
- 对本项目：Phase 3 做“动作预览/取消返还/提示停留”三项即可获得大部分手感收益。

## 3. 1.7 预计内容（截至 2026-10）

**官方已确认（2026-02 十周年公告与视频）**
- 一次免费大型更新正在开发，不是付费 DLC；未公布日期。
- 两名新可婚对象：铁匠克林特、沙漠绿洲店主桑迪。
- 孩子系统升级：孩子更有性格、会自主走动与表情、互动性增强。

**未证实（媒体推测/爆料，不可作为实现依据）**
- 可能新增农场地图、内置农场编辑器与社区分享；来源为二手爆料，官方未确认。

**对齐取舍**：1.7 的“新可婚对象/孩子成长”属于社交与家庭系统，建议放到 Phase 4 之后单独评估；当前不进入 MVP，避免范围膨胀。

## 4. 本项目对齐选择

| 功能（来源） | 落到哪个模块 | 阶段 | 代价/风险 | 决策 |
|---|---|---|---|---|
| 技能满级→精通第二条成长线（1.6） | `systems/skills.gd`（新增）+ HUD | Phase 3 | 中：数据表+阈值+UI | 采纳（精简为 1 条精通线） |
| 昏倒罚金按金币比例、工具不掉落（1.6） | `game_state.pass_out` | Phase 3 | 低 | 采纳 |
| 新作物 4 种（1.6） | `data/crops.gd` 扩表 | Phase 3 | 低 | 采纳（数据驱动，先 1 种验证） |
| NPC 季节服装/条件对白（1.6） | `villager.gd` + 对白条件表 | Phase 3 | 低-中 | 采纳（先季节+好感两条件） |
| 通知停留/取消返还/动作预览（1.6） | `ui/hud.gd`、`actions.gd` | Phase 3 | 低 | 采纳 |
| 大箱子/箱子容量升级（1.6） | 箱子系统（新增） | Phase 4 | 中 | 延后 |
| 加工机器通用框架（1.6 脱水机/熏鱼机等） | `systems/machines.gd`（新增） | Phase 4 | 中 | 延后 |
| 草甸农场/农场类型（1.6） | `world/farm_types.gd`（新增） | Phase 4 | 高（地图+初始物） | 延后 |
| 最小节日框架（1.6 沙漠节） | `systems/festivals.gd`（新增） | Phase 4 | 高 | 延后 |
| 书籍商人/奖券机/神秘盒（1.6） | 商店与奖励系统 | Phase 4 | 中 | 延后 |
| 多宠物/宠物碗/农场搬迁（1.6） | 动物系统（新增） | Phase 4+ | 高 | 延后 |
| 1.7 新可婚对象/孩子成长 | 社交/家庭系统 | Phase 5 评估 | 高 | 不进 MVP |

**不采纳**：多人联机、姜岛/火山、战斗与饰品、Mod API、280 家具等纯内容量扩展（与当前“农场生活 MVP”目标不匹配）。

## 5. 风险与待核实

- 1.7 除“克林特/桑迪可婚、孩子升级、免费更新”外均未官方确认，规划时必须标注“待核实”。
- 1.6 具体数值（精通奖励、机器产出倍率、节日奖励）需逐项查英文 wiki 后再写入 `parity.gd`，不得凭印象。
- 版权：只借鉴机制与交互逻辑，不复制原作美术、角色名、对白、地图与音乐。
