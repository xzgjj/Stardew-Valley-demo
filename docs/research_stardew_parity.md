# 星露谷 1:1 对齐依据（可执行常量版）

日期：2026-10-28。适用工程：`Stardew-Valley-demo`（Godot 4.7.2 / GDScript）。本文只回答一件事：**做 1:1 时哪些数值/规则可以照抄，抄什么，依据在哪**。每条标 **已核实 / 待核实 / 已核实（推导）**；推导链写在同一行，方便复核。

- 核实方式：抓取英文官方 wiki（`stardewvalleywiki.com`，与 `wiki.stardewvalley.net` 同站）正文及文件页元数据；wiki 数值与坊间说法冲突时以 wiki 为准。
- 版权边界：wiki 正文 CC BY-NC-SA 3.0，图片文件页单独标 © ConcernedApe 2016（`File:Standard_Farm.png` 页脚原文），**图片一律不得导入工程**；本文只引用数值与规则。
- 读法：常量表可直接写成 GDScript `const` / 自定义 `Resource`；"待核实"项在实现前必须补证据，不要用记忆补。

## 1. 时间系统

| 常量/规则 | 值 | 说明 | 状态 |
|---|---|---|---|
| 起床时间 | 每天 6:00 | 无论几点睡，次日 6:00 醒 | 已核实 |
| 一天长度 | 6:00 → 次日 2:00，共 20 小时 = 1200 分钟 | 2:00 之后强制结束 | 已核实 |
| 时间粒度 | 10 分钟/刻；内部 `timeOfDay` 600→2600，步长 10 | 600=6:00、1250=12:50、1300=13:00、2600=2:00 | 已核实 |
| 现实时间换算 | **0.7 秒 / 游戏分钟** | 10 分钟=7 秒；1 小时=42 秒；全天=14 分钟；一周=1h38m；一季=6h32m | 已核实 |
| 骷髅洞穴 | 0.9 秒/游戏分钟 | 全天 18 分钟；MVP 不需要 | 已核实 |
| 2:00 昏倒 | 强制结束当天 | 在农舍/小屋内睡着不触发、无罚 | 已核实 |
| 菜单暂停 | 单机：对话、菜单、过场、播放动画时暂停，时钟变灰闪烁 | **打开背包菜单也暂停** | 已核实 |
| 深夜时段换算 | 2:00→6:00 每小时按 100 分钟计（全天折算 1600 分钟） | 影响加工设备；MVP 不需要 | 已核实 |
| 天黑 | 春/夏 20:00，秋 19:00，冬 18:00；室外逐渐变暗 | 室内入夜变暗（有光源除外） | 已核实 |
| 睡觉流程 | 走进床 → 确认对话 → 出货逐项结算 → 存档 → 次日 6:00 醒 | **只在睡觉且接受结算后存档** | 已核实 |

实现建议：`time_of_day:int` 用 600–2600；`_process` 里 `accum += delta; if accum >= 0.7: time_of_day += 10`（0.7 秒 = 1 刻）；`time_of_day >= 2600` 或 `energy <= -15` 触发 `end_day()`。
