# 游戏逻辑设计（v0.1 基线）

本文件描述**玩法实现逻辑**（状态、时序、判定、数据契约），不是设定清单。机制常量以
`scripts/data/parity.gd` 为唯一来源，来源与核实状态见 `docs/research_stardew_parity.md`。
决策：整体“更贴原作”，但首版不做矿洞/战斗/钓鱼/镇民日程；与现作的已知差异见 §14。

## 1. 场景与世界
- 农场 `scenes/main.tscn`：80×65 格，16px/格。农舍外观 7×4（原作 9×5，**待 v1 校正**），
  门在底边中央；出货箱在农舍右侧；邮箱在农舍右下；温室残骸在东北角；池塘在西南；
  两格森林边界；东侧道路预留去公交站出口（本轮不实现切换）。
- 农舍 `scenes/farmhouse.tscn`：当前 14×10（原作内部 10×7，**待 v1 校正**），床 2×2、出口门在底边。
- 场景切换：农场门格 `(15,9)` ↔ 农舍门格 `(7,9)`；切换后玩家落在门外一格，状态不重置。
- 阻挡：水域、建筑占地、树木/石头、村民站位、地图边界；玩家用四个角点查询阻挡格。

## 2. 时间系统
- 状态：`minutes`（360=6:00，1440=次日 0:00，1560=2:00）；`day` 1–28；`season` 0–3；`year`。
- 现实时间到游戏时间：每累计 7.0 秒 +10 游戏分钟（`TICK_SECONDS`/`TICK_MINUTES`）。
- 菜单/对话/日结算/暂停时 `paused=true`，时间冻结（贴原作：对话与开背包暂停）。
- 2:00 判定：`minutes >= 1560` → 昏倒：扣 `min(gold×10%, 1000)`、能量置 135、强制过夜并保存。
- 睡觉时序（一次原子流程）：
  1) 出货箱逐项结算 `gold += Σ(售价×数量)`；2) 浇水作物 `growth+1`（上限成熟天数），清浇水标记；
  3) `day+1`，超过 28 → `day=1, season+1`（超过 4 → 季节回 0、`year+1`）并清空所有地块；
  4) 时钟回 360、能量回 270、水壶补满、`talked_today=false`；5) 存档；6) 发出 `day_started(summary)`。

## 3. 输入与动作解析
| 输入 | 键 | 行为 |
|---|---|---|
| move_* | WASD / 方向键 | 速度 84px/s，四向行走；阻挡格四角检测 |
| use_tool | 空格 | 使用当前栏位 |
| interact | E | 对话/出货箱/门/床/邮箱 |
| hotbar_1..12 | 1-9、0、-、= | 选格 |
| toggle_help / pause_game | Tab / Esc | 帮助 / 暂停 |
动作解析流水线：选中栏位 → 判定物品类别（tool/seed/other）→ 目标格 = 玩家所在格 + 朝向 →
校验（类别、目标、能量、状态）→ 扣能量 → 改状态 → 即时反馈（消息/HUD/地块刷新）。
- 工具表：锄（空地→耕地，2 能量）、水壶（耕地→湿地，2，容量 40；对水面补满）、
  斧（树 hp3→木材×3）、镐（石 hp3→石头×2）、镰刀（杂草 hp1→纤维×1）。
- 失败时能量返还/不扣、状态不变，并输出明确消息。

## 4. 耕作状态机
`未开垦 → 耕地(干) → 耕地(湿)`；播种后 `crop` 写入，生长值 0→4。
- 播种：目标必须是已开垦且无作物的地块；消耗 1 粒种子；季节不匹配拒绝。
- 成长：仅过夜结算时、且当天浇过水，`growth+1`（上限 4）；未浇水不倒退也不生长。
- 收获：`growth>=4` 才可收；先检查背包可容纳，成功则 `growth=0, crop=""` 并放入 1 个防风草。
- 换季：全部地块清空（贴原作枯萎）。
- 数据：防风草 4 天、种子 20g、售价 35g；5 帧生长图（0–3 阶段 + 成熟）。

## 5. 能量
- 上限 270；工具消耗见表；能量不足 → 动作失败并提示；镰刀 0 消耗。
- 睡觉回满；昏倒后 135；暂无“疲惫（0 能量）减速/负能量”细分（原作有，列入 v2）。

## 6. 背包与工具栏
- 12 格；工具不可堆叠（上限 1），其他物品上限 999；选中格 0–11。
- `add`：先合并同类堆，再填空格，返回放不下的数量；`remove`：按格顺序扣减；`can_add` 先验容量。
- 初始：锄/壶/斧/镐/镰刀 + 15 粒防风草种子；金币 500。

## 7. 经济与出货
- 买入：种子店防风草种子 20g/粒，金币不足或背包满则失败。
- 出货：选中非工具物品按 E 放入出货箱（计入 `shipping[id]` 并从背包移除）；过夜结算次日入账。
- 日结算面板显示：第 N 天、季节、出货收入、换季提示。

## 8. 社交
- 每天首次对话 +20 好感（上限 2500，250/心）；对话轮换文本；对话中按 B 打开种子店。
- 好感只影响台词与商店提示，暂无送礼/生日（列入 v2）。

## 9. 存档契约
`user://savegame.json`，JSON 对象：
```json
{"version":1,"day":1,"season":0,"year":1,"minutes":360,"gold":500,"energy":270.0,"water":40,
 "inventory":[{"id":"hoe","count":1},...],"plots":{"15,12":{"crop":"parsnip","growth":2,"watered":true}},
 "shipping":{"parsnip":2},"friendship":20,"talked_today":false,"selected_slot":0,
 "scene":"farm","spawn":[15,12]}
```
- 只接受 `version==1` 且含 `day/gold/inventory` 的档；坏档 → 回退新档，不崩溃。
- 写档时机：睡觉/昏倒后；启动时自动读档。
- 迁移：升级版本必须提供旧档兼容或明确拒绝路径，并在 `docs/decisions.md` 记录。

## 10. 事件流
`GameState` 信号：`changed`（任何状态变化，HUD/场景刷新）、`message`（提示气泡）、
`day_started(summary)`（日结算面板）。场景持有 `player` 与 `hud`；HUD 只读状态，不写。

## 11. 判定失败总表
| 动作 | 失败条件 |
|---|---|
| 锄地 | 已开垦 / 能量<2 |
| 浇水 | 非耕地 / 已浇水 / 水壶空 / 能量<2 |
| 播种 | 非耕地 / 有作物 / 无种子 / 季节不符 |
| 收获 | 非作物 / 未成熟 / 背包满 |
| 砍/敲/割 | 目标类型不符 / 能量不足 |
| 出货 | 选中工具 / 空栏位 |
| 购买 | 金币不足 / 背包满 |
| 对话 | 非 NPC 附近（提示） |
